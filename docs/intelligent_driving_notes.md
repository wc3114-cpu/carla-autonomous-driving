# 智能驾驶技术分析笔记

经过这一阶段的学习，我对智能驾驶系统有了一个比较基础的整体认识。智能驾驶并不是依靠某一个单独的算法完成的，而是由环境感知、行为决策、轨迹规划和车辆控制等多个模块共同组成。可以把整个过程简单理解为：车辆先通过传感器获取周围环境信息，再理解当前道路情况，然后决定下一步应该做什么，最后控制车辆按照规划好的路线行驶。

## 1. 环境感知

环境感知可以理解为智能驾驶系统的“眼睛”。真实车辆通常会使用摄像头、激光雷达、毫米波雷达等传感器来获取周围环境信息。

在本项目中主要使用视觉信息，因此相机是比较重要的传感器。视觉感知中比较常见的任务有目标检测和语义分割。

目标检测主要用于识别车辆、行人和交通标志等目标，同时确定目标在图像中的位置。例如 YOLO 系列算法可以通过 Bounding Box 将目标框出来，并给出目标所属的类别。

语义分割则更加关注图像中的每一个区域。例如把道路、车道线、车辆和建筑物等不同区域区分出来。目标检测主要回答“前面有什么、在哪里”，而语义分割更多解决“哪些区域属于道路、哪些区域可以行驶”的问题。

## 2. 行为决策

车辆完成环境感知之后，还需要根据当前道路情况判断接下来应该采取什么动作，这就是行为决策。

例如正常行驶时，车辆可能需要进行跟车、减速、停车、转弯或者变道。一个比较基础的实现方法是有限状态机，可以提前定义车辆的不同驾驶状态，然后根据环境信息在不同状态之间进行切换。

我觉得行为决策主要解决的是“车辆接下来要做什么”，它连接了感知结果和后面的轨迹规划。

## 3. 轨迹规划

当车辆确定需要进行某个驾驶行为以后，还需要计算具体的行驶路径。

例如车辆决定变道以后，不能直接从一个位置跳到另一个位置，而是需要生成一条连续、平滑的轨迹。同时还需要考虑道路边界、障碍物以及车辆自身的运动能力。

因此轨迹规划解决的是“车辆具体应该怎么走”的问题。常见的方法包括多项式曲线、贝塞尔曲线等。

## 4. 车辆控制

轨迹规划完成以后，需要通过车辆控制模块让汽车真正沿着目标轨迹行驶。

车辆控制主要包括横向控制和纵向控制。纵向控制负责速度，例如油门和刹车；横向控制负责车辆的转向。

本项目后续会使用 PID 控制。PID 的基本思想是根据车辆当前状态与目标状态之间的误差不断调整控制量。例如当前速度低于目标速度时增加油门，超过目标速度时减小油门或者制动。

## 5. CARLA 仿真平台

CARLA 是一个面向自动驾驶研究的仿真平台，可以模拟城市道路、车辆、行人、交通灯以及多种传感器。

真实自动驾驶测试的成本比较高，而且存在一定安全风险，因此可以先在 CARLA 中完成算法开发和验证。通过 CARLA Python API，还可以使用 Python 控制车辆、生成交通参与者、配置相机以及读取仿真环境中的信息。

经过目前的学习，我认为 CARLA 不只是一个车辆驾驶模拟器，更重要的是它提供了一个可以反复进行自动驾驶实验的平台。

## 6. 总结

目前我对整个项目技术路线的理解是：

CARLA 提供仿真道路环境，相机获取道路图像，视觉算法识别车辆、行人、车道线和可行驶区域，然后决策模块根据感知结果判断车辆行为，再通过轨迹规划生成行驶路线，最后使用控制算法控制车辆运动。

我现在对这些模块的理解还比较基础，特别是目标检测、语义分割、轨迹规划和 PID 控制还需要继续深入学习。但通过目前的环境搭建和 CARLA 基础操作，我已经对智能驾驶系统各个模块之间的关系有了一个比较清楚的整体认识。
